## 🔥 About Sexy Arena Ultimate

**Sexy Arena Ultimate** is a modern, frontend-only landing page for a high-performance gaming lounge.  
It features neon aesthetics, cinematic hero section, system rig showcases, gallery, testimonials, booking form, and responsive layout.  
The project demonstrates professional UI design, state management, and interactive elements—all in a single-page experience.

---

## 🚀 Features

<ul>
  <li>💻 <b>System Rig Showcase</b> — cards displaying CPU, GPU, RAM, monitors, and peripherals with hover glow</li>
  <li>🏙️ <b>Arena Highlights Gallery</b> — showcase of booths, stages, and VR corners</li>
  <li>🗣️ <b>Testimonials</b> — feedback from pro players and teams</li>
  <li>📩 <b>Booking Form</b> — reserve solo or team pods easily</li>
  <li>🖤 <b>Dark Mode Friendly</b> — neon aesthetic optimized for dark themes</li>
  <li>📱 <b>Responsive Layout</b> — mobile, tablet, and desktop ready</li>
  <li>✨ <b>CTA Buttons & Footer</b> — neon buttons and footer with Orbitron font</li>
</ul>

## 🧠 Tech Stack

| Technology | Purpose |
|------------|---------|
| ⚛️ **React** | Dynamic UI and interactivity |
| 🧭 **Next.js** | Routing, optimized image handling, SPA |
| 🟦 **TypeScript** | Type safety for props and state |
| 🎨 **Tailwind CSS** | Styling, neon gradients, responsive design |
| 🖼️ **Next/Image** | Optimized and responsive images |
| 🌀 **Framer Motion (Optional)** | Smooth hover and entry animations |
| 🗂️ **Hardcoded Data / Arrays** | Gallery, system rigs, and testimonials |

## 💡 Description

Users can:
